One joke about Monday mornings, written by a program, judged on laughs.
The alarm clock did the paperwork. HR did the rest.

## The joke

> My alarm clock filed an HR complaint this Monday. Waking me at 6 a.m., it says, is a workplace injury. HR agreed — my Mondays now start at noon.

Yes, the alarm clock won. Nobody clocks in at 6 a.m. anymore — not even the clock.

## How it works

`main.ts` (Node 22, stdlib only, deterministic) writes the joke to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. Nothing else is written, nothing is read
from the network, and the same run always produces the same bytes — because
the joke is already perfect, and perfection doesn't need a second draft.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
